🎼 照片 / PDF 自動讀譜設定

聲徑 Studio 的 MusicXML 讀取與播放已內建，但要把照片或掃描 PDF 的五線譜轉成可演奏的音符，還需要在網站伺服器上安裝真正的光學樂譜辨識（OMR）引擎。

本版支援 Audiveris：掃描件 → 本機 Audiveris → MusicXML → 網頁播放。安裝包沒有附上引擎。沒有安裝前，上傳掃描件會明確顯示錯誤，不會產生虛假的音符辨識結果。

1. 安裝 Audiveris

開啟官方發行頁面，選擇你的 Windows 或 Linux 版本，依官方文件安裝。

查看 Audiveris 官方下載

2. Windows 設定（PowerShell）

如果 Audiveris 沒有自動加入 PATH，可以設定 AUDIVERIS_BIN 為實際啟動器的完整路徑。以下路徑只是示範，請自行替換：

$env:AUDIVERIS_BIN = 'C:\實際安裝路徑\bin\audiveris.bat'
py -3 launch.py

3. Linux 設定

確認終端機可執行 audiveris -help，或指定執行檔位置：

export AUDIVERIS_BIN='/your/actual/path/audiveris'
./run-linux.sh

4. 開始辨譜

啟動網站 http://127.0.0.1:5188，上傳印刷鋼琴譜照片或 PDF。辨識成功後核對原譜，再按「演奏樂譜」。

如要檢查後端是否找得到引擎，可開啟 /api/omr-status，其中的 ready: true 只代表找到程式，不代表已通過實譜辨識驗收。

尚未安裝？先用外部工具轉檔

Sheetscan 提供瀏覽器讀譜（初次需要下載辨識模型）；下載 MusicXML 後，再匯入聲徑 Studio 即可播放。

重要限制

Audiveris 主要支援印刷的標準西方五線譜，不支援手寫稿；對歪斜照片、複雜譜面、連音線等也可能有辨識錯誤。服務預設在區網監聽 5188，沒有登入/HTTPS，請勿公開至網際網路。
